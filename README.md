## Objetivo Geral

Desenvolver um banco de dados relacional para uma empresa de aluguel de veículos, com foco em motoristas de aplicativos. A proposta é organizar as principais informações relacionadas aos clientes, atendentes, veículos e contratos de aluguel, permitindo um melhor controle das operações realizadas pela empresa. O banco deverá possibilitar o cadastro dos clientes e atendentes, incluindo a possibilidade de um atendente também ser cliente, além do registro dos veículos disponíveis para aluguel, com informações como placa, marca, modelo e tipo de veículo. Também serão armazenadas as informações dos contratos, relacionando o cliente ao veículo alugado e registrando dados como período de vigência, data do contrato e forma de pagamento.

## Público-alvo

O banco de dados será desenvolvido principalmente para empresas de aluguel de veículos que atendem motoristas de aplicativos, como Uber e 99. O sistema busca facilitar o gerenciamento dos veículos disponíveis e dos clientes que utilizam os veículos para realizar suas atividades profissionais.
